# 同级比较句型 as...as 与否定形式 not as/so...as

**章节**：第13章 七下外研版 (WY) 单元语法与中考核心考点
**出处**：七下外研版 Unit 6 P82 · Hitting the road 核心语法

## 核心规则
1. 肯定句型：主语 + 谓语 + as + 形容词/副词【原级】 + as + 比较对象 (A 与 B 一样...)。
2. 否定句型：主语 + 谓语 + not as/so + 形容词/副词【原级】 + as + 比较对象 (A 不如 B... = B 比 A 更...)。
3. 倍数表达法：倍数 + as + 原级 + as (This room is three times as large as that one).
4. as...as possible 结构：意为“尽可能……”，相当于 as...as sb. can/could (e.g., Run as fast as possible).

## 易错陷阱
【高频陷阱】：在 as...as 中间错误使用比较级！例如误写成 *as better as* 或 *as taller as*，只要看到 as...as，中间有且仅有【原级】！

## 实战演练
### 练习 1
**题目**：Cooking Sichuan hot pot with local friends is just as ______ as visiting the traditional museum.
**选项**：
- A. fun
- B. more fun
- C. most fun
- D. funniest

**正确答案**：A. fun
**解析**：解析：as...as 之间必须使用形容词原级，fun 作形容词意为“有趣的”，原级为 fun。故选 A。

### 练习 2
**题目**：Traveling by high-speed train is convenient, but it is not ______ flying when covering very long distances.
**选项**：
- A. so fast as
- B. as faster as
- C. so faster as
- D. fast than

**正确答案**：A. so fast as
**解析**：解析：否定同级比较结构为 not so/as + 原级 + as，中间必须是原级 fast。故选 A。
